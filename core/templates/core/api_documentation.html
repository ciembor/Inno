Innoradar API v1

Dokumentacja API

Publiczne API JSON udostępnia katalog innowacji wyłącznie do odczytu. Nie wymaga logowania i nie publikuje danych osób zgłaszających ani prywatnych kontaktów.

Szybki start

Adres bazowy: https://maciej-ciemborowicz.eu/inno/api/

curl 'https://maciej-ciemborowicz.eu/inno/api/innowacje/?page=1&page_size=20'

Endpointy

MetodaAdresOpis
GET/api/Opis wersji i zasobów w JSON.
GET/api/innowacje/Stronicowana lista publicznych innowacji.
GET/api/innowacje/{id}/Pełne publiczne dane innowacji, ocena, rekomendacja i partnerzy.

Lista innowacji

GET /api/innowacje/ przyjmuje opcjonalne parametry: page (domyślnie 1) oraz page_size (1–50, domyślnie 20).

{
  "count": 123,
  "page": 1,
  "page_size": 20,
  "next": "/inno/api/innowacje/?page=2&page_size=20",
  "previous": null,
  "results": [{"id": 42, "name": "Nazwa innowacji", "score": 78.5}]
}

Szczegóły innowacji

GET /api/innowacje/{id}/ rozszerza rekord o opis, źródło, rolę instytucji, tagi podobieństwa, oceny kryteriów z uzasadnieniami, rekomendację rozwoju oraz dopasowanych partnerów.

Nieistniejący albo niepubliczny rekord zwraca 404 Not Found. Pola, których nie udało się ustalić ze źródła, mogą mieć wartość null.

Zasady użycia

  • API jest wyłącznie do odczytu — nie oferuje tworzenia, edycji ani usuwania rekordów.
  • Adresy względne w polach url, api_url, next i previous należy połączyć z domeną demonstratora.
  • Oceny i rekomendacje AI mają charakter pomocniczy i wymagają weryfikacji przed podjęciem decyzji.
